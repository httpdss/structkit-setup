# structkit-setup

GitHub Action that installs [StructKit](https://github.com/httpdss/structkit) for CI workflows.

This repository is the installer companion to [structkit-action](https://github.com/httpdss/structkit-action). Call this action first when you need StructKit on `PATH`.
